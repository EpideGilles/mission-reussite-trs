Comment travailler ?

Lis la mission, clique dans les cellules jaunes et saisis une formule qui commence par =. Clique sur Vérifier pour savoir si le résultat est juste. En cas de difficulté, utilise les indices, puis affiche la correction. Tu peux refaire les exercices autant de fois que nécessaire.

📍 Une celluleB2 = colonne B, ligne 2.
➗ Une formule=B2*C2 multiplie les valeurs de deux cellules.
🔎 Une fonction=SOMME(B2:B4) additionne une plage.

Ce tableur pédagogique reproduit les formules essentielles ; il ne remplace pas Excel. Les formules sont présentées en syntaxe française. Les prix et les chantiers sont fictifs.

À toi de jouer : complète les cellules jaunes.
